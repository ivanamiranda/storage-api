# Storage Cloud API 🚀

API desenvolvida em **Kotlin** e **Spring Boot** para gerenciar uploads de arquivos, integrando **PostgreSQL** para metadados e **AWS S3** para armazenamento de objetos.

## 🛠 Tecnologias e Habilidades
- **Linguagem:** Kotlin
- **Framework:** Spring Boot 3
- **Cloud:** AWS S3 (Simulado com LocalStack)
- **Containers:** Docker & Docker Compose
- **Certificação Relacionada:** AWS Cloud Practitioner

## 🚀 Como rodar o projeto
1. Certifique-se de ter o Docker instalado.
2. No terminal, execute: `docker compose up -d`
3. Execute a aplicação via IntelliJ ou `./gradlew bootRun`
